# Evidence Files

The lab evidence is hosted on Google Drive:

**[Download the log files](https://drive.google.com/drive/folders/1Stq7AvkGQppUjpfoBBzVmMLnvhlB0XDH?usp=drive_link)**

It contains:

- **Network capture** — PCAP
- **Firewall logs** — IP, port number, protocol, NGFW
- **IDS logs** — signatures, AI, behaviours
- **Server logs** — authentication, kernel and system logs

Open the PCAP in Wireshark and the logs in any text editor, `grep`, or a SIEM (Splunk, ELK, Wazuh) to follow along with the [analysis](../analysis/).
